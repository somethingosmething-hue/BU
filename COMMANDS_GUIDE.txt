## Setup

1. Copy `.env.example` → `.env` and set your `BOT_TOKEN`
2. Run `npm install`
3. Run `npm start`

**Required permissions:** Send Messages, Manage Roles, Manage Channels, Moderate Members, Ban Members, Kick Members, Add Reactions, Read Message History, Manage Messages, Use External Emojis.

## Divemb

Message Components V2 — enhanced embeds with more options.

**Subcommands:** `create`, `send`, `delete`, `list`, `preview`, `edit`, `view`

### `/divemb create`
```
/divemb create name:welcome
```
Opens a modal with: title, description, color, footer, image, thumbnail, author, url, timestamp, fields.

### `/divemb send`
```
/divemb send name:welcome
/divemb send name:welcome channel:#general
```
Sends the divemb to current or specified channel.

### `/divemb edit`
```
/divemb edit name:welcome field:title value:New Title
/divemb edit name:welcome field:add_field value:Field Name|Field Value|true
```
Edit existing divemb fields directly.

### `/divemb preview`
```
/divemb preview name:welcome
```
Shows how the divemb will look without sending it.

### `/divemb view`
```
/divemb view name:welcome
```
View divemb details and structure.

### `/divemb list`
Lists all saved divembs.

### `/divemb delete`
```
/divemb delete name:welcome
```
Permanently delete a divemb.

## Autoresponder (ar)

Trigger automatic replies when someone sends a specific message.

**Subcommands:** `add`, `remove`, `list`, `info`

### `/ar add`
| Option | Description |
|--------|-------------|
| `trigger` | Text that triggers the response |
| `reply` | The reply (supports placeholders) |
| `match` | `exact` \| `contains` \| `startswith` \| `endswith` \| `regex` |
| `send_type` | `reply` (reply to message) \| `send` (send in channel) |
| `cooldown` | Per-user cooldown in seconds |
| `channel` | Restrict to a specific channel |

**Examples:**
```
/ar add trigger:hello reply:Hey {user_mention}!

/ar add trigger:!rules reply:{divemb:rules-embed} match:exact

/ar add trigger:help reply:Check <#1234567890>! match:contains cooldown:60

/ar add trigger:^hello$ reply:Exact match only! match:regex send_type:send
```

### `/ar remove`
```
/ar remove trigger:hello
```
Remove a specific autoresponder.

### `/ar list`
Shows all active autoresponders and their triggers.

### `/ar info`
```
/ar info trigger:hello
```
Get detailed info about a specific autoresponder.

## Button

Create interactive buttons and select menus.

**Subcommands:** `add`, `addselect`, `remove`, `list`, `panel`

### `/button add` (buttons)
| Option | Description |
|--------|-------------|
| `name` | Internal ID |
| `label` | Button text |
| `reply` | Reply when clicked |
| `color` | `blue` \| `green` \| `grey` \| `red` |
| `emoji` | Emoji on button |
| `cooldown` | Cooldown in seconds |
| `ephemeral` | Reply visible only to clicker? (`true`/`false`) |

**Examples:**
```
/button add name:open-ticket label:Open Ticket reply:Staff will be with you! color:green

/button add name:verify label:Verify reply:{addrole:Member} Welcome! color:green ephemeral:true

/button add name:support label:Get Help emoji:🆘 reply:Support team incoming! color:blue cooldown:5
```

### `/button addselect` (select menus)
| Option | Description |
|--------|-------------|
| `name` | Internal ID |
| `placeholder` | Placeholder text |
| `options` | `label\|value\|desc` (comma separated) |
| `reply` | Reply (use `{value}` for selected option) |
| `cooldown` | Cooldown in seconds |

**Examples:**
```
/button addselect name:color-select placeholder:Choose a color options:Red|red|Blood red,Blue|blue|Cool blue,Green|green|Forest green reply:You chose {value}!

/button addselect name:role-select placeholder:Pick your role options:Gamer|gamer|Gaming enthusiast,Artist|artist|Creative person,Developer|dev|Code wizard reply:{addrole:{value}} Role added!
```

### `/button panel`
```
/button panel components:open-ticket,verify message:Click below!
```
Create a panel with multiple buttons together.

### `/button list`
Lists all saved buttons and select menus.

### `/button remove`
```
/button remove name:open-ticket
```
Delete a button or select menu.

## Custom Commands (cc)

**Subcommands:** `add`, `remove`, `list`, `info`

### `/cc add`
```
/cc add name:help response:Check <#1234567890> for help!

### `/cc info`
```

```

## User Variables (cvar)

Custom user variables — build your own economy!

**Subcommands:** `set`, `get`, `add`, `remove`, `list`, `clear`

### `/cvar set`
```
/cvar set name:money value:100 user:@User
/cvar set name:points value:0 user:@User
```
Set a variable to a specific value.

### `/cvar get`
```
/cvar get name:money user:@User
```
Retrieve a variable's current value.

### `/cvar add` (increment number)
```
/cvar add name:money amount:50 user:@User
/cvar add name:points amount:10 user:@User
```
Add to an existing variable.

### `/cvar remove` (decrement)
```
/cvar remove name:money user:@User
```
Subtract from a variable (decrements by 1, or use negative amounts).

### `/cvar list`
```
/cvar list user:@User
```
Show all variables for a user.

### `/cvar clear`
```
/cvar clear user:@User
```
Clear all variables for a user.

### Using variables in replies
Use `%%var:name%%` in any reply:
```
/cc add name:daily response:You earned 100 coins! {cvar:add:money:100}

/cc add name:balance response:Your balance: %%money%% coins
```
Or in math: `%%100 + %%money%%%%`

## Reaction Events

Trigger actions when someone adds a reaction to a message.

**Subcommands:** `add`, `remove`, `list`, `edit`

### `/reactevent add`
| Option | Description |
|--------|-------------|
| `message_id` | Message ID to watch |
| `emoji` | Emoji to trigger on |
| `response` | Reply/action |
| `action` | `reply` \| `send` \| `add_role` \| `remove_role` |
| `role` | Role for add_role/remove_role |
| `channel` | Channel the message is in |

**Examples:**
```
/reactevent add message_id:123456789 emoji:🎮 response:You got the Gamer role! action:add_role role:@Gamer

/reactevent add message_id:987654321 emoji:✅ response:Verified! action:add_role role:@Verified channel:#verification

/reactevent add message_id:555555555 emoji:👍 response:Thanks for the reaction! action:send
```

### `/reactevent remove`
```
/reactevent remove message_id:123456789 emoji:🎮
```
Remove a reaction event.

### `/reactevent list`
Shows all active reaction events.

### `/reactevent edit`
```
/reactevent edit message_id:123456789 emoji:🎮 response:New response
```
Modify an existing reaction event.

## Level

XP and leveling system (disabled by default). Enable via `/level config enabled:true`.

**Subcommands:** `config`, `setreward`, `reset`, `xp`, `level`, `rank`, `leaderboard`

### `/level config`
```
/level config enabled:true
/level config enabled:false
/level config levelup_channel:#level-ups
/level config disable_levelmsgs:true
/level config disable_levelmsgs:false
/level config xp:10
```
Configure the leveling system.

### `/level setreward`
```
/level setreward level:5 role_given:@Role perk_message:Extra Giveaway Entry
/level setreward level:10 role_given:@VIP perk_message:VIP member!
```
Set rewards for reaching certain levels.

### `/level reset`
```
/level reset user:@User
```
Reset a user's XP and level.

### `/level xp`
```
/level xp add user:@User amount:100
/level xp remove user:@User amount:100
/level xp set user:@User amount:500
```
Manually manage user XP.

### `/level lvl`
```
/level lvl add user:@User amount:1
```
Manually add levels to a user.

### `/level rank`
```
/level rank
/level rank user:@User
```
Check your rank or another user's rank.

### `/level leaderboard`
```
/level leaderboard
/level leaderboard type:global
```
View the XP leaderboard.

### Prefix Commands (Legacy)
```
c!lb

,lb
c!rank / ,rank / c!level / ,level
```

## Reminder

Personal reminders.

**Subcommands:** `set`, `list`, `cancel`

### `/reminder set`
```

/reminder set time:1h message:Meeting in 30 mins

## Mod

Moderation tools.

**Subcommands:** `ban`, `unban`, `kick`, `timeout`, `untimeout`, `warn`, `warnings`, `delwarn`, `purge`, `slowmode`, `lock`, `unlock`, `nickname`, `modlogs`

### `/mod ban`
```
/mod ban user:@User reason:Spamming
/mod ban user:@User reason:Hate speech delete_message_days:7
```
Ban a user from the server.

### `/mod unban`
```
/mod unban user:@User reason:Appeal accepted
```
Unban a user.

### `/mod kick`
```
/mod kick user:@User reason:Rules violation
```
Kick a user from the server.

### `/mod timeout`
```
/mod timeout user:@User duration:10m reason:Spam
/mod timeout user:@User duration:1h reason:Inappropriate behavior
```
Timeout (mute) a user. Duration format: `30s`, `5m`, `1h`, `7d`, etc.

### `/mod untimeout`
```
/mod untimeout user:@User reason:Early release
```
Remove timeout from a user.

### `/mod warn`
```
/mod warn user:@User reason:Keep it civil
```
Issue a warning to a user.

### `/mod warnings`
```
/mod warnings user:@User
```
Check warnings on a user.

### `/mod delwarn`
```
/mod delwarn user:@User warn_id:1
```
Delete a specific warning.

### `/mod purge`
```
/mod purge amount:50
/mod purge amount:100 user:@User
```
Delete messages in bulk. Optionally from a specific user.

### `/mod slowmode`
```
/mod slowmode duration:5m
/mod slowmode duration:0
```
Set slowmode (0 to disable).

### `/mod lock`
```
/mod lock channel:#general reason:Raid
```
Lock a channel (members can't send messages).

### `/mod unlock`
```
/mod unlock channel:#general
```
Unlock a channel.

### `/mod nickname`
```
/mod nickname user:@User nickname:NewName
```
Change a user's nickname.

### `/mod modlogs`
```
/mod modlogs user:@User
```
View mod action history for a user.

## Variables & Placeholders

### Text Placeholders
| Placeholder | Replaces |
|-------------|----------|
| `{user_mention}` | @Username |
| `{user_name}` | Username |
| `{user_tag}` | Username#0000 |
| `{user_id}` | User ID |
| `{user_avatar}` | Avatar URL |
| `{server_name}` | Server name |
| `{server_icon}` | Server icon URL |
| `{member_count}` | Member count |
| `{date}` | Today's date |
| `{time}` | Current time |
| `{timestamp}` | Unix timestamp |
| `{newline}` | Line break |

### Action Placeholders
| Placeholder | Effect |
|-------------|--------|
| `{addrole:Role}` | Adds a role |
| `{removerole:Role}` | Removes a role |
| `{requirerole:Role}` | Blocks if user lacks role |
| `{react:emoji}` | Reacts to message |
| `{embed:name}` | Uses saved embed |
| `{divemb:name}` | Uses saved divemb |
| `{embed:#hex}` | Colored embed |
| `{addbutton:name}` | Attaches button |
| `{addselect:name}` | Attaches select menu |
| `{addlinkbutton:Label\|url}` | Link button |
| `{cooldown:seconds}` | Sets cooldown |

### Custom Variables
| Syntax | Description |
|--------|-------------|
| `%%var:name%%` | Get user's variable |
| `{cvar:add:name:amount}` | Add to variable (in replies) |

### Math Expressions
```
%%100 + %%money%%%%
%%myvar - 50%%
%%score * 2%%
```
